# 🎬 API Películas - Backend

API REST para gestionar un catálogo de películas: géneros, directores, productoras y contenido multimedia asociado. Desarrollada con Node.js, Express y MongoDB Atlas.

## 🚀 Tecnologías utilizadas

- Node.js
- Express
- MongoDB Atlas

## 📂 Estructura del proyecto

- controllers/ → Lógica de cada recurso
- models/ → Esquemas de MongoDB
- routes/ → Endpoints de la API
- db/ → Conexión a la base de datos
- index.js → Punto de entrada

## ✨ Funcionalidades

- CRUD completo de Géneros
- CRUD completo de Directores
- CRUD completo de Productoras
- CRUD completo de Tipos
- CRUD completo de Media
